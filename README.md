# 👥 HR Employee Attrition Prediction

This project is a Machine Learning-based web application that predicts whether an employee is likely to leave the organization (attrition) based on various HR-related features.

The application is built using **Python, Scikit-learn, and Streamlit**, providing an interactive interface for both single and batch predictions.

---

## 🚀 Features

- 🔮 Predict employee attrition (Yes/No)
- 📊 Probability score for attrition
- 📁 Batch prediction using CSV upload
- 🎯 Clean and interactive UI using Streamlit
- 📦 Pre-trained ML model using real-world HR features

---

## 🧠 Machine Learning

- Model trained on HR dataset
- Supports classification models (e.g., Logistic Regression / Random Forest / etc.)
- Includes:
  - Feature preprocessing
  - Model training
  - Model evaluation (Accuracy, ROC-AUC)
